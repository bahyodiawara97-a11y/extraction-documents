# Versions minimales plutôt qu'exactes, à une exception près.
#
# Un `==` fige la version compilée disponible le jour où on l'écrit. Sur une
# machine de déploiement dont le Python est plus récent, cette version précise
# n'a jamais été compilée : pip télécharge alors le code source et tente de le
# compiler sur place — ce que pandas, Pillow et pydantic (Rust) ne supportent
# pas dans un conteneur de build limité. D'où `>=`, qui laisse pip choisir une
# version compilée pour le Python en face.

pytesseract>=0.3.13         # OCR local (nécessite le binaire tesseract, voir README)
